# Review: Issue #258 — Mail Release Tag Realignment

Reviewed with: Codex

Issue: https://github.com/dave0875/HealthDelta/issues/258

## Summary
- The `mail.fitness-pals.com` deployment had drifted to ad hoc image tag `issue247-live` even though the repo already had release-style tags and GitHub Releases.
- The host was realigned to the latest existing release tag `v0.0.10` without changing other runtime settings.
- Post-deploy verification confirms the container image, `/healthz`, and `/version` now reflect release lineage.

## Risks / Gaps
- [severity: low] The `mail` host currently follows an ORIN-style compose layout without a dedicated repo runbook, so future drift is still possible until the deployment path is standardized for this host.
- [severity: low] Immediate post-restart health checks can race the process start; one transient connection reset occurred before the service reached steady state.
