# Review: Issue #259 — Automated Drive-to-mail Baseline Refresh

Reviewed with: Codex

Issue: https://github.com/dave0875/HealthDelta/issues/259

## Summary
- Added a one-shot automation script that turns the validated manual full-baseline refresh path into a repeatable GORF-side operation with no-op detection, baseline build, `mail` promotion, and post-promotion verification.
- Added a runbook and checked-in `systemd --user` templates for polling the prior Drive source every 15 minutes.
- Verified the local automation contract with focused tests.

## Findings
- [severity: medium] Live activation is still blocked by expired Google Drive credentials on GORF. `rclone lsjson 'gdrive:HEALTH/Exports/export.zip' --hash` currently fails with `invalid_grant`, so the timer must not be enabled until `rclone config reconnect gdrive:` is completed.

## Risks / Gaps
- [severity: low] The script assumes `rclone`, `ssh`, `rsync`, and the HealthDelta venv are stable on GORF; the runbook documents those prerequisites but does not install them automatically.
- [severity: low] Optional malformed-member exclusion is operator-configured via `--exclude-member`; if a future export has a different failure mode, the operator still needs to inspect the profile/build logs.
